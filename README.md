# 小红书上传

一款面向普通用户的小红书图文上传工具。把图片和文案拖进窗口，软件会自动识别内容、上传素材，并将笔记保存到小红书草稿箱，方便发布前再次检查。

> 软件只保存草稿，不会自动公开发布笔记。

## 主要功能

- 拖入图片或整个图片文件夹，自动按顺序读取
- 支持 JPG、PNG、WebP、HEIC 等常见图片格式
- 单篇图文最多上传 18 张图片
- 支持 Markdown、TXT、RTF、Word 文案文件
- 自动识别标题、正文和话题标签
- 自动将话题添加为小红书可点击的话题
- 上传前自动关闭“允许正文复制”
- 上传完成后自动保存到草稿箱
- 遇到登录、验证码或安全验证时暂停，等待手动处理

## 下载与安装

请打开仓库右侧的 **Releases** 页面，进入最新版本，在 **Assets** 中下载与你电脑匹配的安装包。

### macOS

- Apple 芯片（M1、M2、M3、M4 等）：下载文件名中带有 `arm64` 的 `.dmg`
- Intel 芯片：下载文件名中带有 `x64` 的 `.dmg`

打开下载的 `.dmg` 文件，将“小红书上传”拖入“应用程序”文件夹，然后从“应用程序”中启动。

如果首次打开时系统提示无法验证开发者，请前往：

**系统设置 → 隐私与安全性 → 仍要打开**

确认后再次启动软件。

### Windows

下载 `.exe` 安装包并双击安装。本软件目前支持 Windows 64 位系统。

如果 Windows 出现安全提醒，请确认安装包来自本仓库的 Releases 页面，再选择“更多信息”并继续运行。

## 使用说明

### 1. 准备图片

将本次笔记需要的图片放在同一个文件夹中。建议提前按希望发布的顺序整理文件名。

支持一次选择多张图片，也可以直接拖入整个图片文件夹，最多 18 张。

### 2. 准备文案

软件支持 Markdown、TXT、RTF 和 Word 文档。推荐按下面的格式编写，识别最稳定：

```text
标题：
这里填写笔记标题

正文：
这里填写笔记正文。

#穿搭 #日常分享 #小红书
```

软件会自动识别：

- “标题”后的第一段文字作为标题
- “正文”后的内容作为正文
- 以 `#` 开头的内容作为话题，最多识别 10 个

### 3. 导入素材

打开软件后：

1. 将图片或图片文件夹拖入左侧区域，也可以点击选择
2. 将文案文件拖入右侧区域，也可以点击选择
3. 检查软件显示的图片数量、标题、正文字数和话题

### 4. 上传并保存草稿

点击 **“发布到小红书”**。软件会打开一个专用的 Chrome 窗口，并自动完成图片上传、标题与正文填写、话题添加和草稿保存。

首次使用时，需要在打开的 Chrome 窗口中登录小红书。登录成功后返回软件重新操作即可，之后通常不需要重复登录。

### 5. 检查并发布

软件提示“草稿已保存”后，请打开小红书创作中心，在草稿箱中检查图片顺序、标题、正文和话题。确认无误后，再由你手动发布。

## 系统要求

- macOS：Apple 芯片或 Intel 芯片 Mac
- Windows：64 位 Windows 系统
- 电脑已安装 Google Chrome
- 可以正常访问小红书创作中心
- 拥有可正常登录和发布内容的小红书账号
- 上传期间保持网络连接稳定

## 常见问题

### 为什么点击后没有直接发布？

这是软件的安全设计。它只负责上传并保存草稿，避免未经检查就公开发布。请在小红书草稿箱确认内容后手动发布。

### 首次使用为什么会打开 Chrome？

软件通过专用 Chrome 窗口完成登录和上传。首次使用需要登录一次小红书，登录状态会保存在本机，正常情况下以后会自动沿用。

### 出现验证码、扫码登录或安全验证怎么办？

请在软件打开的 Chrome 窗口中手动完成验证。完成后回到软件重新点击上传。

### 软件提示没有识别到标题或正文怎么办？

请检查文案文件是否包含清晰的“标题：”和“正文：”标记，并确保标记后有实际内容。建议使用上方示例格式。

### 图片顺序不正确怎么办？

软件会按文件名顺序读取文件夹中的图片。可在上传前将图片重命名为 `1.jpg`、`2.jpg`、`3.jpg` 等，再重新导入。

### 为什么有的话题没有添加成功？

单篇笔记最多支持 10 个话题。话题还需要能在小红书的话题列表中匹配到；建议使用简短、常见且准确的话题名称。

### 支持视频吗？

当前版本仅支持小红书图文笔记，不支持视频上传。

### 可以同时登录多个小红书账号吗？

当前版本会沿用上传专用 Chrome 中的登录账号。如需切换账号，请先在该窗口退出当前账号，再登录另一个账号。

### 关闭或移动软件后，登录状态会丢失吗？

正常情况下不会。登录状态保存在电脑的应用数据目录中，而不是安装包所在位置。

### 上传失败怎么办？

请依次检查：

1. 网络是否正常
2. Chrome 中的小红书账号是否仍处于登录状态
3. 是否出现验证码或安全验证
4. 图片是否超过 18 张
5. 文案中是否包含标题和正文

处理后重新上传即可。若仍然失败，请在仓库的 **Issues** 页面反馈，并附上系统版本、软件版本、错误提示和运行日志截图。请勿上传账号密码、验证码或其他隐私信息。
